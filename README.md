# 🎓 EBAC — Módulo 14: Sites rápidos e responsivos com Bootstrap

## 📖 Sobre

Exercício do módulo de Bootstrap: layout responsivo usando o grid system (`row`/`col-md-6 col-lg-4`) e componentes de navegação.

## 🚀 Como visualizar

Abra o `index.html` no navegador.

## 🛠️ Tecnologias

HTML5 • Bootstrap 5

## 💡 O que aprendi

- Grid responsivo do Bootstrap (breakpoints `md`/`lg`)
- Navbar e utilitários de espaçamento
